# 天气 · Weather

浮屿（Fuyu）插件。收起条显示当前天气图标与温度，点开是整页预报：头部是城市与实况，中间七天卡片，底部 24 小时逐时折线与降雨概率。默认按网络定位所在城市，定位不准可以改成手动填城市。

## 功能

- **两种定位方式**：`自动定位` 按网络出口 IP 判断城市，面板头部显示城市名并带「自动定位」标记；`手动` 自己填城市名，中文或拼音都行。自动定位偏到隔壁城市时，面板页脚有「定位不准？改手动」直接进设置
- **收起条**：天气图标 + 当前温度，点一下刷新，悬停显示城市、天气与降雨提示
- **面板**：城市、温度、天气描述、体感 / 湿度 / 气压 / 云量 / 紫外线 / 日出日落，七日卡片，24 小时折线（含温度曲线与降雨概率）
- **下雨提醒**：未来 1/2/3 小时内降水概率过阈值就弹通知，正在下雨时静默，同一场雨两小时冷却
- **单位与刷新**：摄氏度 / 华氏度，10 / 15 / 30 / 60 分钟取一次数；`Ctrl+Alt+W` 手动刷新

## 数据来源

**定位**（`src/host.ts`，逐级降级，全部失败才报错）

| 顺序 | 接口 | 说明 |
|---|---|---|
| 1 | `ipwho.is` | HTTPS，免 key，返回英文地名 |
| 2 | `ipapi.co` | 备用，部分网络会被挡（返回 HTML 而不是 JSON） |
| 3 | `ip-api.com` | HTTP，`lang=zh-CN` 直接给中文地名 |

拿到坐标后再用 BigDataCloud 的 `reverse-geocode-client?localityLanguage=zh` 换成中文地名（「南通市 / 江苏省」→ 显示「南通, 江苏」）；反查失败就用 IP 库自带的名字。定位结果缓存在 `dataDir/locate.json`，常规 6 小时，手动刷新时 1 分钟内复用，接口全断就沿用上次坐标。

**预报**（Open-Meteo，免 key）

- `geocoding-api.open-meteo.com/v1/search`：手动城市名 → 坐标（同名地点优先国内行政中心）
- `api.open-meteo.com/v1/forecast`：`current` + `hourly`（24 小时）+ `daily`（7 天）

四个定位域名与两个 Open-Meteo 域名都写在 `package.json` 的 `fuyu.network` 白名单里。

## 面板版式

以 **775px** 为版心（设计稿原尺寸），窄了等比缩：缩放系数 `--wx-u = clamp(0.68, 页宽 / 775, 1)`，所有尺寸写成 `calc(N × var(--wx-u))`，字号带下限。缩到 0.68（约 527px）打住，再小字就糊了。

- **七天**：始终 7 列自适应，放不下就横滑（滚动吸附；鼠标竖向滚轮落到这里会转成横向）
- **逐小时**：固定 4 列一屏，24 小时 = 6 屏，一次翻一屏，下方圆点可点；折线每屏单独画，并把屏外相邻的点也带上，跨屏不断头
- **今天**：灰底 + `#1268bd` 蓝边，和设计稿一致
- **图标**：全部 emoji（⛅️ 🌧️ ☁️ ☀️ 🌙 🌫️ ⛈️，日出日落 🌅🌇）

`mock.html` 是按设计稿 1:1 做的静态版式稿，仅用于对照尺寸与配色，不参与构建。

## 设置

| 项 | 说明 |
|---|---|
| 定位方式 | `auto` 按网络定位；`manual` 用手填的城市 |
| 城市（手动） | 只在手动方式下使用，中文或拼音都行 |
| 温度单位 | 摄氏 / 华氏 |
| 下雨提醒 | 开关；正在下雨时不提醒，同一场雨两小时内只提醒一次 |
| 看未来几小时 | 1 / 2 / 3 小时，接口是逐小时数据，提醒文案会写明几点 |
| 降水概率阈值 | 30 / 50 / 70 |
| 刷新间隔 | 10 / 15 / 30 / 60 分钟 |

## 已知限制

- **网络定位只到「出口 IP 所在城市」**，不是 GPS。同一台机器实测过两家库分别给苏州和无锡（出口 IP 在轮换），出差跨网、开代理都会偏——所以手动方式是必需的兜底
- 逐小时数据决定了提醒只能落在整点，做不到「20 分钟后下雨」这种精度
- 面板的湿度、气压、紫外线来自同一份 `hourly` / `current` 响应，接口缺字段时显示 `—`，不会编数
